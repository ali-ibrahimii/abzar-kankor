# قابلیت‌های نقش‌محور به سبک Coursera — ابزار کانکور

این سند توضیح می‌دهد سایت چطور به یک پلتفرم دوره‌محور با دو نقش **استاد** و **شاگرد** تبدیل شده، هر نقش چه کارهایی می‌تواند انجام دهد، و داده‌ها کجا ذخیره می‌شوند.

---

## ۱) حساب‌های نمایشی

| نقش | ایمیل | رمز عبور |
| --- | --- | --- |
| استاد | `teacher@abzar.dev` | `123456` |
| شاگرد | `student@abzar.dev` | `123456` |

- در `/login` دکمه‌های «ورود به عنوان استاد» و «ورود به عنوان شاگرد» هست.
- در داشبورد، کلید «نمایش به‌عنوان» بین دو حساب نمایشی جابه‌جا می‌کند تا هر دو داشبورد را ببینی.
- در `/register` نقش را انتخاب می‌کنی؛ حساب جدید در همان مرورگر ساخته می‌شود.
- داده‌های نمونه در اولین بازدید از `/login`، `/register`، `/dashboard` یا `/instructors/...` ساخته می‌شوند.

---

## ۲) داشبورد استاد

| بخش | امکانات |
| --- | --- |
| نمای کلی | ۶ کارت آمار (دوره، منتشرشده، شاگرد، درس، میانگین پیشرفت، تمرین ارسالی) + دوره‌های پرطرفدار + آخرین ثبت‌نام‌ها + دسترسی سریع |
| دوره‌های من | ساخت دوره، ویرایش کامل، انتشار/لغو انتشار، حذف، دیدن در سایت |
| شاگردان | فهرست ثبت‌نام‌ها، فیلتر بر اساس دوره، درصد پیشرفت، تعداد درس تکمیل‌شده، تاریخ ثبت‌نام |
| ارزیابی | خواندن پاسخ تمرین‌ها، فیلتر وضعیت، ثبت نمره و بازخورد |
| پیام‌ها | صندوق پیام‌های فرم تماس + حذف |
| تنظیمات | پروفایل (نام، تخصص، بیو)، زبان، بازنشانی داده‌ها |

### ویرایشگر دوره

- اطلاعات پایه: عنوان، توضیح، دسته‌بندی، سطح، قیمت، وضعیت انتشار، رنگ و آیکن
- خروجی‌های یادگیری و پیش‌نیازها (هر خط یک مورد)
- فصل‌ها با عنوان و ترتیب
- درس‌ها: عنوان، خلاصه، مدت، نوع (متن/ویدیو/آزمون)، متن درس، لینک ویدیو
- تمرین‌ها: عنوان، توضیح، بارم
- ذخیره در `localStorage["abzar-courses"]`

دورهٔ تازه پیش‌فرض «پیش‌نویس» است. با انتشار، بلافاصله در `/school` و کاتالوگ شاگرد دیده می‌شود. آدرس صفحهٔ دوره `/school/<slug>` است.

---

## ۳) داشبورد شاگرد

| بخش | امکانات |
| --- | --- |
| نمای کلی | ۵ کارت آمار + کارت «ادامهٔ یادگیری» + دوره‌های اخیر + درس بعدی |
| دوره‌های من | درصد پیشرفت، تعداد درس تکمیل‌شده، ادامهٔ یادگیری، صفحهٔ دوره |
| همهٔ دوره‌ها | جست‌وجو در دوره‌های منتشرشده + ثبت‌نام |
| تمرین‌های من | ارسال پاسخ، دیدن وضعیت، نمره و بازخورد استاد |
| گواهینامه‌ها | گواهینامهٔ دوره‌های ۱۰۰٪ تکمیل‌شده + کد گواهینامه + دوره‌های در حال یادگیری |
| تنظیمات | پروفایل، زبان، بازنشانی داده‌ها |

### ثبت‌نام و یادگیری

1. از «همهٔ دوره‌ها» یا صفحهٔ دوره، ثبت‌نام کن.
2. ثبت‌نام در `localStorage["abzar-enrollments"]` ذخیره می‌شود.
3. فضای یادگیری: `/learn/<course-slug>/<lesson-id>`
4. در هر درس: متن/ویدیو، علامت تکمیل، درس قبلی/بعدی، یادداشت شخصی (ذخیره در مرورگر) و نوار پیشرفت.
5. با ۱۰۰٪ پیشرفت، پیام گواهینامه و کارت گواهینامه در داشبورد فعال می‌شود.

---

## ۴) صفحهٔ دوره و پروفایل استاد

- صفحهٔ دوره: عنوان، توضیح، مدرس، امتیاز، تعداد شاگرد، مدت، سطح، خروجی‌ها، سرفصل‌ها، برنامهٔ درس (آکاردئون) و تمرین‌ها.
- دکمهٔ ثبت‌نام / ادامهٔ یادگیری + درصد پیشرفت برای کاربر واردشده.
- لینک پروفایل مدرس: `/instructors/<id>` شامل بیو، آمار و دوره‌های منتشرشده.
- دوره‌های ساخته‌شده توسط استاد در همان کاتالوگ عمومی نمایش داده می‌شوند؛ محدود به موضوع‌های از پیش تعریف‌شده نیست.

## ۵) مدل داده (خلاصه)

```ts
Course {
  id, slug, title, description, category, level, price,
  status: "draft" | "published", color, icon,
  instructorId, instructorName, instructorTitle,
  outcomes[], requirements[],
  modules: { id, title, lessons: { id, title, summary, minutes, type, content, videoUrl }[] }[],
  assignments: { id, title, description, points }[],
  chapters?[], rating?, baseStudents?, createdAt, updatedAt
}

Enrollment { id, courseId, userId, completed[], enrolledAt, lastActivityAt }
Submission { id, courseId, assignmentId, userId, userName, text, status, score?, feedback?, createdAt }
User { id, name, email, password, role: "student" | "teacher", headline, bio, createdAt }
```

تعریف کامل در `src/lib/types.ts` و منطق در `src/lib/store.ts` و `src/lib/courses.ts` است.

## ۶) نقشهٔ مسیرها

| مسیر | توضیح |
| --- | --- |
| `/school` | کاتالوگ همهٔ دوره‌ها (موضوع‌های سایت + دوره‌های استادان) |
| `/school/[slug]` | صفحهٔ دوره |
| `/learn/[slug]` | هدایت به اولین درس |
| `/learn/[slug]/[lessonId]` | فضای یادگیری |
| `/instructors/[id]` | پروفایل استاد |
| `/login`, `/register` | ورود/ثبت‌نام با نقش |
| `/dashboard` | داشبورد نقش‌محور |
| `/about` | دربارهٔ ما + معرفی دو مسیر استاد/شاگرد |
| `/contact` | تماس → صندوق پیام استاد |

---

## ۷) ذخیره‌سازی نمایشی

| کلید | محتوا |
| --- | --- |
| `abzar-users` | کاربران ثبت‌نام‌شده + دو حساب نمایشی |
| `abzar-user` | نشست فعلی |
| `abzar-courses` | دوره‌های ساخته‌شده (و دوره‌های نمونه) |
| `abzar-enrollments` | ثبت‌نام‌ها و درس‌های تکمیل‌شده |
| `abzar-submissions` | پاسخ تمرین‌ها + نمره/بازخورد |
| `abzar-messages` | پیام‌های فرم تماس |
| `abzar-notes-<userId>` | یادداشت درس‌ها |
| `abzar-demo-seeded` | پرچم ساخت دادهٔ نمونه |

برای نسخهٔ واقعی: عملیات `store.ts` را با API جایگزین کنید (احراز هویت، دوره‌ها، ثبت‌نام، نمره و پیام‌ها). ساختار UI وابسته به محل ذخیره‌سازی نیست.

---

## ۸) محدودیت‌های نسخهٔ نمایشی

- رمزها به‌صورت ساده در مرورگر ذخیره می‌شوند (فقط برای دمو).
- داده‌ها بین مرورگرها/دستگاه‌ها همگام نمی‌شوند.
- آپلود فایل ویدیو پیاده نشده؛ استاد لینک ویدیو ثبت می‌کند.
- محتوای دوره‌های ساخته‌شده توسط استاد یک‌زبانه است؛ متن‌های ثابت سایت سه‌زبانه‌اند.
- امکانات آینده: نظرات و امتیازدهی شاگرد، آزمون چندگزینه‌ای داخل درس، اعلان‌ها، آپلود فایل و پرداخت.

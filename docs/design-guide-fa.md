## ۲) قابلیت‌های اضافه‌شده

- **سه زبان**: فارسی/دری، پشتو، انگلیسی — با تعویض از هدر و ذخیره در کوکی.
- **داشبورد نقش‌محور**: داشبورد جدا برای استاد (ساخت دوره، شاگردان، ارزیابی، پیام‌ها) و شاگرد (دوره‌ها، کاتالوگ، تمرین‌ها، گواهینامه‌ها).
- **جست‌وجوی موضوع‌ها** در صفحهٔ مکتب.
- **فلش‌کارت تعاملی** با فیلتر موضوع.
- **فرم تماس** که پیام را ذخیره می‌کند و در داشبورد نمایش می‌دهد.
- **حساب نمایشی با انتخاب نقش** (استاد/شاگرد)، **دوره‌های قابل ساخت توسط استاد**، ثبت‌نام شاگرد، فضای یادگیری، تمرین و ارزیابی، گواهینامه، و **پروفایل عمومی استاد**.
- **سوالات متداول**، **کتابخانهٔ عمومی**، **فورم‌های کانکور**، **صفحهٔ ۴۰۴**، **sitemap/robots**، **حالت تاریک**.

## ۴) پوشهٔ `messages` — منبع یگانهٔ همهٔ متن‌ها

هر سه فایل **دقیقاً یک ساختار** دارند. کلیدهای اصلی:

| کلید | محتوا |
|---|---|
| `meta` | نام زبان، جهت (rtl/ltr)، کد کوتاه |
| `site` | نام، شعار، توضیح، ایمیل، شبکه‌های اجتماعی |
| `nav` | برچسب‌های هدر (خانه، مکتب، داشبورد، …) |
| `menus` | متن مگامنوی مکتب و فلش‌کارت |
| `common` | واژه‌های مشترک (درس، فصل، دقیقه، جست‌وجو…) |
| `home` | تمام متن‌های صفحهٔ اصلی (هیرو، بخش‌ها، FAQ، CTA) |
| `stats` | چهار آمار |
| `subjects` | ۶ موضوع با فصل‌ها |
| `lessons` | درس‌های تازه |
| `tools` | سه ابزار |
| `books` | ۷ کتاب (school/general) |
| `faq` | سوالات متداول |
| `flashcards` | متن صفحه + ۶ کارت |
| `pages` | متن اختصاصی هر صفحه (مکتب، AI، کتابخانه، فورم‌ها، دانلود، درباره، تماس، ورود، شروع سریع، ۴۰۴) |
| `dashboard` | تمام برچسب‌های داشبورد |
| `footer` | متن‌های فوتر |

### افزودن یا تغییر متن

1. متن فارسی را در `src/messages/fa.json` تغییر بده.
2. همان مسیر کلید را در `ps.json` و `en.json` هم به‌روز کن.
3. بررسی کن:

```bash
npm run check:messages
```

این اسکریپت ساختار هر سه فایل را مقایسه می‌کند و اگر کلیدی کم/زیاد باشد یا طول آرایه‌ها فرق کند، بیلد را متوقف می‌کند (به‌صورت `prebuild` هم اجرا می‌شود).

## ۵) سیستم زبان

- زبان در کوکی `locale` ذخیره می‌شود (`fa` | `ps` | `en`).
- `getDictionary()` در سرور، زبان را می‌خواند و دیکشنری + جهت را برمی‌گرداند.
- `<html lang dir>` و همهٔ صفحه‌ها بر همان اساس رندر می‌شوند.
- تعویض زبان: `LanguageSwitcher` کوکی را ست می‌کند و `router.refresh()` می‌زند.
- اعداد با `Intl.NumberFormat` و لوکال مناسب (fa-IR / ps-AF / en-US) قالب می‌شوند.

> توجه: چون زبان از کوکی خوانده می‌شود، صفحات به‌صورت داینامیک رندر می‌شوند (در خروجی بیلد با `ƒ` مشخص شده‌اند). برای کش کامل می‌توان بعداً به مسیر `/[locale]` مهاجرت کرد.

## ۶) داشبورد

مسیر: `/dashboard` — نقش کاربر از روی حساب فعلی خوانده می‌شود و داشبورد مناسب همان نقش رندر می‌شود.

### استاد

| بخش | کارکرد |
|---|---|
| نمای کلی | آمار دوره/شاگرد/درس/پیشرفت/تمرین + دوره‌های پرطرفدار + آخرین ثبت‌نام‌ها |
| دوره‌های من | ساخت و ویرایش دوره (فصل، درس، تمرین)، انتشار/لغو انتشار، حذف، دیدن در سایت |
| شاگردان | ثبت‌نام‌ها با فیلتر دوره، پیشرفت و تعداد درس تکمیل‌شده |
| ارزیابی | خواندن پاسخ تمرین‌ها، ثبت نمره و بازخورد |
| پیام‌ها | صندوق پیام فرم تماس + حذف |
| تنظیمات | پروفایل، زبان، بازنشانی داده‌ها |

### شاگرد

| بخش | کارکرد |
|---|---|
| نمای کلی | آمار ثبت‌نام/درس/پیشرفت/گواهینامه/ساعت + ادامهٔ یادگیری + درس بعدی |
| دوره‌های من | درصد پیشرفت و ادامهٔ یادگیری |
| همهٔ دوره‌ها | جست‌وجو و ثبت‌نام در دوره‌های منتشرشده |
| تمرین‌های من | ارسال پاسخ، دیدن نمره و بازخورد |
| گواهینامه‌ها | گواهینامهٔ دوره‌های ۱۰۰٪ تکمیل‌شده + کد گواهینامه |
| تنظیمات | پروفایل، زبان، بازنشانی داده‌ها |

- کلید «نمایش به‌عنوان» بین دو حساب نمایشی استاد/شاگرد جابه‌جا می‌کند.
- ذخیره‌سازی در `localStorage` است (کلیدهای `abzar-courses`, `abzar-enrollments`, `abzar-submissions`, `abzar-users`, `abzar-user`, `abzar-messages`, `abzar-notes-*`, `abzar-demo-seeded`).
- برای نسخهٔ واقعی، لایهٔ ذخیره‌سازی در `src/lib/store.ts` با API/دیتابیس جایگزین می‌شود؛ ساختار داده در `src/lib/types.ts` است.
- جزئیات کامل نقش‌ها و جریان‌ها: `docs/coursera-features-fa.md`.

## ۸) اجرا و بررسی

```bash
npm install
npm run dev            # http://localhost:3000
npm run check:messages  # بررسی هم‌خوانی سه زبان
npm run build && npm run start
```

موارد باقی‌مانده برای نسخهٔ واقعی: اتصال فرم تماس و داشبورد به API، لینک واقعی استورها، ایمیل و شبکه‌های اجتماعی واقعی، و دامنهٔ `NEXT_PUBLIC_SITE_URL`.
